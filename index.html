数据通道与部署说明 直连

学校接口没有开放跨域（CORS），所以从 *.github.io 直接请求会被浏览器拦下。 页面支持两种取数方式：域名下同源部署时用「直连」即可；部署在 GitHub Pages 时， 把下面的地址换成一个自建中转（仓库 relay/ 里有 Cloudflare Worker 和本地 Node 两种实现）， 中转只做转发、不保存任何数据，因此依然不影响多用户隔离。
